# Тест-кейсы для банковского приложения XYZ

**Объект тестирования:** [https://www.globalsqa.com/angularJs-protractor/BankingProject/#/manager](https://www.globalsqa.com/angularJs-protractor/BankingProject/#/manager)

---

### Тест-кейс №1: Создание нового клиента

**ID:** TC-001
**Название:** Успешное создание нового клиента с корректными данными.

**Предусловия:**
1.  Открыт браузер Chrome.
2.  Осуществлен переход на страницу менеджера по адресу объекта тестирования.

**Шаги:**
1.  Нажать на кнопку "Add Customer".
2.  Сгенерировать тестовые данные:
    *   10-значный почтовый индекс (Post Code).
    *   Имя (First Name) на основе почтового индекса согласно заданной логике.
    *   Фамилия (Last Name), например, "Тестов".
3.  Ввести сгенерированное имя в поле "First Name".
4.  Ввести сгенерированную фамилию в поле "Last Name".
5.  Ввести сгенерированный почтовый индекс в поле "Post Code".
6.  Нажать кнопку "Add Customer" под формой.
7.  Принять всплывающее уведомление (alert) браузера.
8.  Перейти в раздел "Customers".
9.  Убедиться, что созданный клиент присутствует в таблице.

**Ожидаемый результат:**
*   После нажатия на кнопку "Add Customer" (шаг 6) появляется системное уведомление (alert) с текстом вида "Customer added successfully with customer id :X", где X - номер клиента.
*   После перехода в раздел "Customers", в таблице присутствует запись с только что созданными данными (First Name, Last Name, Post Code).

### Тест-кейс №2: Сортировка клиентов по имени

**ID:** TC-002
**Название:** Проверка корректности сортировки таблицы клиентов по имени (First Name).

**Предусловия:**
1.  Открыт браузер Chrome.
2.  Осуществлен переход на страницу менеджера.
3.  В системе существует как минимум два клиента с разными именами.

**Шаги:**
1.  Перейти в раздел "Customers".
2.  Получить список имен клиентов из таблицы.
3.  Нажать на заголовок столбца "First Name" для активации сортировки.
4.  Получить список имен клиентов из таблицы после сортировки.
5.  Сравнить полученный список с эталонным, отсортированным по возрастанию (A-Z).
6.  Снова нажать на заголовок столбца "First Name".
7.  Получить список имен клиентов из таблицы после повторной сортировки.
8.  Сравнить полученный список с эталонным, отсортированным по убыванию (Z-A).

**Ожидаемый результат:**
*   После первого нажатия (шаг 3) список имен в таблице отсортирован в алфавитном порядке (A-Z).
*   После второго нажатия (шаг 6) список имен в таблице отсортирован в обратном алфавитном порядке (Z-A).

### Тест-кейс №3: Удаление клиента

**ID:** TC-003
**Название:** Удаление клиента, длина имени которого наиболее близка к среднему арифметическому длин всех имен.

**Предусловия:**
1.  Открыт браузер Chrome.
2.  Осуществлен переход на страницу менеджера.
3.  В системе существует как минимум один клиент.

**Шаги:**
1.  Перейти в раздел "Customers".
2.  Получить полный список имен всех клиентов из таблицы.
3.  Вычислить среднее арифметическое длин всех имен.
4.  Найти в списке имя, длина которого имеет минимальное отклонение от среднего арифметического. Это искомое имя для удаления.
5.  Найти в таблице строку с искомым именем и нажать кнопку "Delete" в этой строке.
6.  Проверить, что клиент с искомым именем больше не отображается в таблице.

**Ожидаемый результат:**
*   Клиент, чье имя было выбрано для удаления, пропадает из таблицы клиентов.
*   Количество строк в таблице уменьшается на одну.
