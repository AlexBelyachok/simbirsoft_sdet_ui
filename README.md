# 🧪 UI Тесты для банковского проекта — XYZ Bank  

---

## 📖 Описание  
Проект предназначен для автоматизации тестирования модуля **“Manager”** на сайте  
👉 [GlobalSQA Banking Project](https://www.globalsqa.com/angularJs-protractor/BankingProject/#/manager)  

Автотесты реализованы с использованием **Selenium WebDriver**, **Pytest** и **Allure Reports**, по архитектурному шаблону **Page Object Model (POM)**.  

---

## ⚙️ Используемые технологии  
- **Python 3.10+**  
- **Selenium WebDriver**  
- **Pytest**  
- **Allure Framework**  
- **WebDriver Manager**  
- **Faker** — генерация тестовых данных  

---

## ✅ Тест-кейсы  

### **ТС001 — Добавление клиента**  
**Цель:** Проверить успешное создание нового клиента.  

**Шаги:**  
1. Перейти во вкладку **Add Customer**.  
2. Сгенерировать данные:  
   - Post Code — случайный 10-значный номер  
   - First Name — сгенерированное имя  
   - Last Name — *AutoTest*  
3. Заполнить форму и нажать **Add Customer**.  
4. Подтвердить появившийся **alert**.  
5. Перейти во вкладку **Customers** и убедиться, что клиент появился в списке.  

**Ожидаемый результат:** Клиент успешно добавлен и отображается в таблице.  

---

### **ТС002 — Сортировка клиентов по имени**  
**Цель:** Проверить корректность сортировки списка клиентов по полю **First Name**.  

**Шаги:**  
1. Перейти во вкладку **Customers**.  
2. Нажать на заголовок **First Name**.  
3. Считать текущий порядок имён.  
4. Проверить, что список отсортирован по возрастанию или убыванию.  

**Ожидаемый результат:** Имена клиентов отображаются в корректно отсортированном порядке.  

---

### **ТС003 — Удаление клиента**  
**Цель:** Проверить успешное удаление клиента из списка.  

**Шаги:**  
1. Перейти во вкладку **Customers**.  
2. Найти клиента в таблице.  
3. Нажать кнопку **Delete** напротив его имени.  
4. Обновить список клиентов.  

**Ожидаемый результат:** Клиент успешно удалён и больше не отображается в таблице.
